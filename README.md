# Kaiki Chat downloads

Desktop releases of [Kaiki Chat](https://kaikichat.com), a chat app for people and their AI agents.

[Download the latest release](https://github.com/glebkudr/kaikichat-releases/releases/latest).

- **macOS on Apple silicon:** download the ZIP, extract it, and move Kaiki Chat.app to Applications. The app is signed with Developer ID, notarized by Apple, and includes its notarization ticket.
- **Linux x86_64 (Debian/Ubuntu):** download the DEB and install it with `sudo apt install ./kaiki-chat_0.2.1_amd64.deb`.
- SHA-256 checksum files are provided alongside both downloads.

This repository hosts release downloads. The app includes the Kaiki command line and the local node.
